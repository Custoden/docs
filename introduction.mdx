---
title: "Custoden API"
description: "A free, public API for checking open-source dependencies and CI pipelines before they reach your environment. No account or API key."
---

```bash
curl https://api.custoden.com/v1/packages/npm/expres
```

```json
{
  "ecosystem": "npm",
  "name": "expres",
  "version": "0.0.5",
  "verdict": "review",
  "risk": "medium",
  "findings": [
    {
      "id": "possible-typosquat",
      "severity": "medium",
      "title": "Name resembles popular package \"express\"",
      "detail": "\"expres\" differs from the widely used \"express\" by one or two characters. Confirm you meant this package."
    }
  ]
}
```

## Base URL

```
https://api.custoden.com
```

All responses are JSON. Requests with a body accept JSON, and the workflow endpoint also accepts raw YAML.

## Data sources

* Package metadata and published artifacts from the npm registry and PyPI
* Vulnerability and malware advisories from [OSV](https://osv.dev), which includes the GitHub Advisory Database and the OpenSSF Malicious Packages dataset
* Download counts from the npm downloads API and [pypistats.org](https://pypistats.org)
* Workflow runs, repository metadata and repository files from GitHub
* Indicators and techniques from published campaign research. See [Threat intelligence](/reference/threat-intelligence)

Workflows, package contents and repository files are analyzed in memory and not stored.
